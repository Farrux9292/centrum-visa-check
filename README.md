# Centrum Air Visa Check — публикация и Telegram-бот

Три файла в этом проекте:

- `index.html` — весь сайт, один файл, без сборки. Раздел «Проверить на сайте»
  (ссылки на официальные проверки виз) работает сразу после публикации.
- `api/analyze-visa.js` — серверная функция для раздела «Скан визы по фото».
  Без неё сайт по-прежнему работает, просто сканирование покажет сообщение,
  что бэкенд не настроен.
- `telegram_bot.py` — бот, который открывает сайт как кнопку в Telegram.

Важно: фото-сканирование визы использует ИИ (Claude). Внутри Claude.ai это
работает бесплатно "из коробки", но на обычном сайте так нельзя — ключ API
нельзя класть в код, который выполняется в браузере пользователя. Поэтому
для этой функции нужен свой ключ Anthropic API и шаг 2 ниже. Если сканирование
не нужно — можно пропустить шаг 2 и оставить только каталог сайтов.

## Шаг 1. Опубликовать сайт (нужен HTTPS-адрес для Telegram)

Самый простой вариант — Vercel (бесплатно, поддерживает и `index.html`,
и папку `api/`):

1. Зарегистрируйтесь на vercel.com (можно через GitHub, Google или email).
2. Загрузите папку `centrum-visa-check` (например через vercel.com → Add New
   → Project → перетащить папку, либо `npx vercel` из терминала в этой папке).
3. После деплоя Vercel даст адрес вида
   `https://centrum-visa-check-xxxx.vercel.app` — это и есть ваш `WEBAPP_URL`.

Если функция сканирования не нужна — подойдёт ещё проще: Netlify Drop
(netlify.com/drop) — просто перетащить папку в браузере, без регистрации,
сайт получит HTTPS-адрес за несколько секунд. Раздел с ссылками при этом
будет работать полностью.

## Шаг 2 (опционально). Включить ИИ-сканирование визы

1. Зарегистрируйтесь на console.anthropic.com, откройте Settings → API Keys,
   создайте ключ.
2. В настройках проекта на Vercel: Settings → Environment Variables →
   добавьте `ANTHROPIC_API_KEY` со значением ключа → Redeploy.
3. Сканирование фото визы заработает. Учтите: каждый вызов расходует платный
   баланс на вашем аккаунте Anthropic API (см. цены на anthropic.com).

## Шаг 3. Создать Telegram-бота

1. В Telegram напишите @BotFather → `/newbot` → задайте имя и username.
2. BotFather пришлёт токен (строка вида `123456:ABC-DEF...`) — это `BOT_TOKEN`.

## Шаг 4. Подключить сайт к боту — два способа

**А) Без кода (быстрее всего).** В диалоге с @BotFather:
```
/setmenubutton
```
→ выберите вашего бота → пришлите текст кнопки, например «Открыть Visa Check»
→ пришлите ваш `WEBAPP_URL` из шага 1.
Теперь у бота внизу экрана появится кнопка, открывающая сайт как мини-приложение.
Больше ничего писать не нужно.

**Б) Через свой бот-скрипт** (если хотите команду `/start` с текстом и кнопкой):
```bash
pip install pyTelegramBotAPI
export BOT_TOKEN="ваш токен от BotFather"
export WEBAPP_URL="https://ваш-адрес.vercel.app"
python telegram_bot.py
```
Бот должен быть постоянно запущен (на своём компьютере, VPS или сервисе
вроде Railway/Render), иначе он офлайн и не отвечает.

## Проверка

Откройте бота в Telegram, нажмите кнопку — сайт должен открыться внутри
Telegram как мини-приложение, растянутое на весь экран.
